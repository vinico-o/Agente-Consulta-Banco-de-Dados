# Agente de Consulta

Interface inspirada em ferramentas de IA moderna para realizar consultas inteligentes a bancos de dados através de linguagem natural.

## Tecnologias

- **React**
- **TypeScript & TSX**
- **Vite**
- **CSS3**
- **HTML5**

## Como executar o projeto

1. Acesse a pasta do frontend:

   ```bash
   cd agente-consulta
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```
